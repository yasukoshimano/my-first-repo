# ビジネスプロセス インタビュースクリプト生成ツール

ビジネスプロセスの変更において、現状業務のインタビューやヒアリングを行う際に、業務の暗黙知を効果的に引き出すためのインタビュースクリプトを自動生成するWebアプリケーションです。

## 概要

業務改革やシステム導入のプロジェクトでは、現場の業務を正確に理解することが成功の鍵となります。しかし、マニュアルに書かれていない暗黙知や、ベテラン社員の経験則を聞き出すのは容易ではありません。

このツールは、業務プロセスの情報を入力するだけで、暗黙知を効果的に引き出すための構造化されたインタビュースクリプトを生成します。

## 主な機能

### 1. カスタマイズ可能な入力項目
- 業務プロセス名
- 対象部門
- インタビュー対象者の役割
- 変更の背景・現状の課題
- インタビューの目的
- 質問の重点項目（6カテゴリから選択可能）

### 2. 6つの質問カテゴリ
- **業務フロー・手順**: 業務の流れと詳細な手順を把握
- **判断基準・意思決定**: 暗黙の判断基準を明確化
- **例外処理・イレギュラー対応**: 通常フローでは捉えられない対応を把握
- **他部署・システム連携**: 依存関係とインターフェースを確認
- **必要なスキル・暗黙知**: ベテランのノウハウを言語化
- **課題・改善ポイント**: 現場の課題意識を収集

### 3. インタビュアー向けのガイダンス
- 各セクションに「インタビュアーへのTip」を表示
- 質問の掘り下げ方のポイントを提示
- 暗黙知を引き出すための質問テクニックを提供

### 4. 便利な出力機能
- 生成されたスクリプトをクリップボードにコピー
- テキストファイルとしてダウンロード
- 日付と業務名を含むファイル名で保存

## 使い方

### 1. アプリケーションを開く
ブラウザで `index.html` を開きます。

```bash
# ローカルで開く場合
open index.html

# または、簡易サーバーを起動
python3 -m http.server 8000
# ブラウザで http://localhost:8000 にアクセス
```

### 2. 情報を入力
必須項目（業務プロセス名、対象部門、対象者の役割）を入力し、必要に応じて背景や目的を記載します。

### 3. 重点項目を選択
インタビューで重点的に聞きたい項目にチェックを入れます（デフォルトは全選択）。

### 4. スクリプトを生成
「スクリプトを生成」ボタンをクリックすると、カスタマイズされたインタビュースクリプトが表示されます。

### 5. スクリプトを活用
- 「コピー」ボタンでクリップボードにコピー
- 「ダウンロード」ボタンでテキストファイルとして保存
- 印刷してインタビュー時に持参

## スクリプトの構成

生成されるインタビュースクリプトには以下が含まれます：

1. **ヘッダー情報**: 対象業務、部門、対象者、背景、目的
2. **オープニング**: アイスブレイクと目的説明
3. **業務概要の確認**: 全体像を把握する質問
4. **選択したカテゴリ別の質問**: 各7問程度の詳細な質問
5. **クロージング**: 総括と今後の確認
6. **インタビュー実施時の注意点**: ベストプラクティス集
7. **質問テクニック**: 暗黙知を引き出す5つのテクニック
